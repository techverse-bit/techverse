The problem

Our people want AI. Our data can’t leave the bank.

Employees could save hours every week with AI help on research, analysis and documents. Today there is no safe way for them to use it with bank data.

01
Executive summary

A private AI lab for research, inside the bank.

The AI Lab gives employees a secure AI assistant for AI research, analysis and questions on internal material. It runs two leading open models, Qwen3.6-35B-A3B for deep reasoning and Gemma-4-26B-A4B for fast answers, and a router sends each request to the better fit automatically.

We evaluated two ways to host it: two Apple Mac Studio M5 Ultra machines with 256GB of memory each, or one server with an NVIDIA A100 80GB GPU. We recommend the Mac Studio lab: it costs more up front, but gives 6× the memory for larger research models, stays online if a machine fails, uses less power and runs with standard IT skills.

Architecture

How it works: a front door, a brain and an engine.

Every request follows the same short path. It enters through one portal, is checked by one gateway, and is answered by the Mac Studios, all inside a closed network.

Front door
AI Lab portal
Employees sign in with their bank login, book a slot, then chat, run research tasks or upload documents.
→
Brain
Mac mini gateway
The only way in. Guardrails block personal data and secrets, then the router picks Qwen or Gemma.
→
Engine
2× Mac Studio
Run the models on MLX. If one Mac stops, the other carries on. Every answer is checked before it is shown.
Sealed: no internet in or outMonitored: live Grafana dashboard for health, usage and alerts

If something fails

  • A Mac Studio: traffic moves to the other automatically, at 50% capacity
  • A guardrail: requests are held, so nothing passes unvalidated
  • Mac mini: restored from backup; an optional standby ($2.5K) removes the pause
  • Power cut: everything restarts automatically

Running the lab

  • Daily: dashboard review
  • Weekly: review of blocked prompts and errors
  • Monthly: macOS and security updates, one Mac at a time
  • Quarterly: new models tested on one Mac Studio first; capacity review

Start with two Mac Studios and a pilot.

The Mac Studio lab gives research teams 6× the memory of a GPU server, stays online if a machine fails and is simpler to run. It grows one Mac at a time, in step with demand.

Appendix B · How we valued employee time

Time saved, counted at half its value.

The return in section 08 treats an hour of employee time as money. We count only half of each hour saved, because not every saved minute turns into extra work.

AI Lab architecture

How the AI Lab works.

An employee signs in to the portal and books a session. Each request then passes through the gateway, which checks access and runs the safety checks; the router chooses the model, and the load balancer sends it to a free Mac Studio. Fair-use limits on each request keep the lab fast for everyone. Almost every component is proven, ready-made open-source software, and Prometheus, Elasticsearch and Grafana on the Mac mini show the lab’s health and usage live.

Privacy & data sovereignty

No prompt, document or answer ever leaves the bank. Two layers protect the data.

Layer 1 · Closed perimeter

  • No internet and no outside AI services
  • Only the Mac mini gateway is reachable, over HTTPS; the Mac Studios never are
  • Chat history deleted after 7 days of inactivity; logs hold no prompt text

Layer 2 · Request inspection

  • Gitleaks blocks passwords, API keys and tokens
  • Presidio blocks Aadhaar, PAN, card and account numbers
  • Qwen3Guard screens prompts and checks every answer; if a check is down, requests are held

Who’s guarding the guards?

The AI harness: a model only turns text into text; these layers make it useful and safe at work.
